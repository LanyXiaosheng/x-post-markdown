# Chrome Web Store listing

## 标题

XMD · 帖子归档

## 简短说明

免费将 X/Twitter 帖子、已展开长文和评论导出为 Markdown；支持批量选择，本地处理，无需激活。

## 详细说明

把值得留下的内容，保存下来。

XMD 将当前 X/Twitter 页面中已经加载的帖子、长文和评论转换为本地 Markdown，
方便保存到笔记应用、知识库或普通文本编辑器。

主要功能
• 单帖快捷导出：点击帖文旁边的细线下载图标。
• 批量选择：打开弹窗，自动识别已加载内容，默认全选，可逐条取消。
• 帖子/评论筛选：只导出所选类型；评论可以汇总为一个文件，也可以追加到对应帖子下。
• 长文格式：支持页面已经展开的标题、段落、加粗、列表、引用、链接、代码和 HTML 表格。
• 图文顺序：将已识别的图片链接保留在正文相应位置。
• 表情保留：将 Emoji 输出为字符。
• 文件命名：普通帖子按用户名和 ID 命名；长文优先使用标题。
• 快捷入口：工具栏弹窗、帖文按钮、右键菜单和 Ctrl+Shift+M（可在 Chrome 中调整）。

隐私和使用方式
• 当前版本全部功能免费，不要求账号、激活码或支付。
• 内容在浏览器本地转换，不上传到开发者服务器，没有广告或使用分析。
• 不请求 X API Key，不读取密码、登录 Cookie 或完整浏览历史。

使用限制
• 只导出当前页面已加载、已展开且可被识别的内容，不自动遍历全部历史或书签。
• 图片和视频保留为远程链接，不下载媒体文件。
• 批量提交下载期间请保持弹窗打开；同名文件由 Chrome 自动追加序号。
• X 页面结构变化可能影响识别和格式，需要相应更新。

XMD 是独立开发的工具，不隶属于 X Corp.，不代表其官方产品。

## 单一用途

将用户在 X/Twitter 当前页面中选择的已加载帖文、长文和评论转换并下载为本地 Markdown。

## 权限用途

activeTab：用户打开弹窗时识别当前标签页，并与该页内容脚本通信；不读取完整浏览历史。
contextMenus：在 X/Twitter 页面显示导出 Markdown 的右键菜单。
downloads：将用户选择的内容保存为本地 .md 文件，并为同名文件生成新名字。
X/Twitter 站点权限：只在这些站点读取相关帖文 DOM、展示导出图标并返回用户请求的内容。
远程代码：不使用。执行代码全部包含在 ZIP 中，不从服务器加载代码或执行远程脚本。

## 数据披露准备

处理的网站内容：所选帖文正文、作者显示名/用户名、时间、原帖/媒体链接。
处理目的：仅用于本地 Markdown 导出。开发者不接收、保存、出售或共享这些内容。
若控制台把本地处理列入“收集/处理”范围，按实际字段定义披露“网站内容”；
不要因没有上传就作出“完全不接触网站数据”的不实声明。

## 审核测试说明

1. 安装后打开 X/Twitter。需要查看登录内容时，使用审核人员自己的 X 账号。
   本扩展没有独立账号、测试激活码或支付要求。
2. 打开包含可见帖文的主页、搜索页或帖文详情页，等待内容加载。
3. 打开扩展弹窗，确认已加载内容被列出并默认选中，按帖子/评论筛选。
4. 点击“导出选中内容”，确认 Chrome 开始下载 Markdown 文件。
5. 单条导出可点击帖文右上角的灰色下载箭头。
6. 对长文请先展开页面内容；扩展只导出当前实际加载的 DOM。
